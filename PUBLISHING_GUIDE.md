# Publish this portfolio for free

## Fastest route: GitHub Pages
1. Sign in to GitHub or create a free account at https://github.com.
2. Click **New repository**. Name it `jayendra-network-portfolio` and choose **Public**.
3. Upload `README.md`, `index.html`, and the `projects` folder from this package. Keep the folder structure exactly the same.
4. Open the repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. Wait a few minutes. GitHub will show the website URL in the Pages section.
8. Open the URL on mobile and desktop and test every project link.

## Before publishing
- Review the content and confirm job dates and certification names.
- The README says CCNA only if earned; change it only if accurate.
- Replace the public email placeholder if you want contact details visible.
- Add your own topology images and screenshots only after testing.
- Clearly label projects as “Lab” or “Design” until you have actually built and verified them.
- Never upload passwords, VPN keys, customer names, real circuit IDs, public IPs, or confidential diagrams.
