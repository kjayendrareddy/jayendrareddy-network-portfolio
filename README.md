## How I Troubleshoot
1. Define the impact, affected users/sites, and start time.
2. Check physical link, power, interface status, and cabling.
3. Verify IP address, subnet mask, gateway, DHCP, and DNS.
4. Check VLAN membership, trunk allowed VLANs, STP state, and routing.
5. Test hop-by-hop using ping/traceroute and inspect device logs/counters.
6. Check firewall policy/NAT/VPN state if traffic crosses a security boundary.
7. Apply an approved change, validate service, document the cause and resolution.
